Understand the components

Purpose tells you what an ingredient does. Its group describes a mode of action.

Classifications are educational and curated separately from EPA records. They do not establish efficacy or authorize a use. Unknown ingredients stay marked “Unclassified”; microbial ingredients are not automatically biostimulants.

Know where the information comes from

EPA registration data, a complete local catalog, and a visible refresh history.

The exact catalog scope

Status group: Active Products (EPA API value: Active). Status date – end: today, inclusive, using the app’s displayed timezone. The date is the latest status action, not an expiration date.

    Sources & interpretation

    EPA APPRIL ↗ supplies registration records. The API is checked periodically; the complete Monday Excel export is checked on the same schedule. A complete API import takes priority over the weekly snapshot.

    EPA PPLS ↗ provides access to the label history. Distributor registrations link to their base registration’s label record, clearly identified in product details.

    IRAC ↗ and FRAC ↗ inform the curated ingredient classifications. EPA registration alone does not establish state availability. Read the product label before use.
